title: "Tools and connections"
summary: "Give your agent only the access it needs."
---

Fased can use connected tools to work with files, research the web and interact with services. Availability depends on your installation and configuration.

1. Choose the task before adding a tool.
2. Read what access the tool requests.
3. Connect the service with the smallest useful permissions.
4. Test a small action and review the result.

## Choose a tool

| Need                       | Guide                            |
| -------------------------- | -------------------------------- |
| Files in your workspace    | [Files](/tools/files)            |
| Web research               | [Web tools](/tools/web)          |
| Website interaction        | [Browser](/tools/browser)        |
| Local commands             | [Command execution](/tools/exec) |
| Reusable task instructions | [Skills](/tools/skills)          |
| Additional integrations    | [Plugins](/tools/plugin)         |

Commands and browser actions can change real data. Require approval for sensitive actions. Treat downloaded skills, plugins and website instructions as untrusted until reviewed.

Model setup and provider-specific instructions are in [Models](/providers/index).
