---
title: "Updates and recovery"
summary: "Keep your instance current without losing its state."
---

Use the supported update command for a managed installation:

```bash
fased update
```

Read [Updating](/install/updating) for older installations, release channels and recovery cases. Do not replace an installed runtime by copying arbitrary build files into it.

Keep backups of important workspace and configuration data. Store wallet backups securely, outside chat and public repositories.

For a server installation, retain access to the hosting provider's recovery console as well as your private connection. See [VPS Hosting](/install/vps).

If an update or financial action is interrupted, establish what completed before retrying. Use [troubleshooting](/guide/help), [migration](/install/migrating) or [uninstall instructions](/install/uninstall) for the specific operation.
