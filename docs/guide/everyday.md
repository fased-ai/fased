## Give your agent a task

Open Chat in your Fased control panel. State the outcome you want, provide relevant files or context, and say which actions require your approval. Start with a read-only task such as summarizing a document.

Review the result before letting the agent change files, send messages or use funds. Model output can be wrong.

## Keep useful context

Use a conversation for related work. Keep durable instructions and files in your workspace, and start a new conversation when the task changes. See [workspace](/concepts/agent-workspace) and [memory](/concepts/memory) for details.

## Schedule repeat work

For recurring tasks, specify what to do, when to run and when to notify you. Your instance must stay running for its scheduled work. Review the [scheduling guide](/automation/cron-jobs) before enabling unattended actions.

## Connect a channel

Use the browser first. Add a [supported channel](/channels/index) when you want to talk to your agent elsewhere. Pair only accounts you trust and check who can send instructions.

## Watch costs and results

Model providers and connected services may charge for usage. Keep tasks bounded, review logs when something fails, and disable automation you no longer need.
