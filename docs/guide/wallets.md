---
title: "Wallet safety"
summary: "Keep financial permissions separate from ordinary chat."
---

Wallets are optional. Set up your agent and tools before adding funds.

Use **Control UI → Wallets** to manage supported wallets. Start with a small amount and confirm the network, address and asset. Never put a private key or recovery phrase in chat.

## Before approving an action

- Confirm the wallet, recipient and asset.
- Review the amount, fees and any continuing spending permission.
- Keep enough funds for network costs where required.
- If the result is uncertain, check the transaction before trying again.

Connecting a wallet does not mean approving every financial action. Give each automation only the permissions it needs and revoke access when it is no longer useful.

## Setup and recovery

Follow [wallet setup](/plugins/crypto/wallet-page) for the supported screens and [wallet policies](/plugins/crypto/wallet-roles-and-policies) for available controls. Use [RPC setup](/plugins/crypto/wallet-rpc-setup) only when configuring a blockchain connection.

Protect your machine, backups and service credentials. Self-hosting does not make an unsafe permission safe.

New WEN automation is [in development](/wen/index). Existing SAT users should use the [legacy recovery guidance](/plugins/crypto/mining-troubleshooting) for their installed version.
