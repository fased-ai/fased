# Operator glossary

- **Agent**: the assistant configuration that owns sessions, tools, and tasks.
- **Task**: a scheduled or requested unit of work with its own execution record.
- **Wallet**: a signer or external account selected for an operation.
- **Policy**: the permitted operations, assets, destinations, and spending limits for a wallet.
- **WEN**: the current SAT program integration. See [WEN](/wen/index) for Devnet configuration and evidence.
- **Fased Network**: identity, directory, and relay functions for network participation.

See [Wallets](/plugins/crypto/wallet-page) and [Tasks](/concepts/agents-sessions-tasks).
