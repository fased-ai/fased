# Wallet and network boundaries

Fased supports ordinary wallet operations under signer policy and current WEN SAT Devnet workflows. The retired Satcoin miner, federation bond, bond staking, and paid marketplace economy have been removed.

Wallet setup, spending limits, and reviewed operations are described in [Wallets](/plugins/crypto/wallet-page). Current WEN program configuration and Devnet evidence are described in [WEN](/wen/index).

Fased Network retains identity, directory, and relay functions. Network membership does not establish a bond balance, reward entitlement, or wallet spending permission.
