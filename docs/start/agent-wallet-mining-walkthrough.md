summary: "Start with the agent, then add wallet permissions when needed."

Follow [Getting started](/start/getting-started) to install Fased and connect a model. Add wallets only when you need financial actions, using [wallet safety](/guide/wallets) and the setup guide for your installed release.

For a VPS, follow the complete [Hosting guide](/install/vps) for the installation command, private access and recovery.

WEN mining automation is [in development](/wen/index). It is not a requirement for using Fased.
