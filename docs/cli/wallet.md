# Wallet CLI

Use `fased wallet --help` for the commands shipped with your installed version. Create an ordinary wallet with an optional name and verified RPC; do not select an Agent, Mining or Vault role. The Control UI provides ordinary creation and permission management with the same Local and Hosting workflow.

Native import, encrypted recovery and explicit owner export keep private material outside browser forms, gateway requests and chat. Creation returns the public identity; it does not automatically display a private key. Follow the exact installed command's secure input and confirmation prompts.

New wallets are read-only. Financial actions require matching signer policy and exact owner approval or bounded delegation. Assign a wallet explicitly to an agent or task; its name is not spending authority.

After an uncertain submission, use the retained operation journal to reconcile the original request. Restarting or changing a default wallet must not repeat a purchase or redirect recovery.

See [Wallets](/plugins/crypto/wallet-page), [Wallet policies](/plugins/crypto/wallet-roles-and-policies), and [Wallet operations and recovery](/plugins/crypto/wallet-production-flow).
