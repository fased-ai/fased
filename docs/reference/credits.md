# Origin and Credits

## Current project

Fased is the current product direction for this repository.

The public repo is maintained as the Fased agent/runtime surface and now centers on:

- self-hosted agent operations
- gateway and control UI
- wallets and signer policy
- Fased Network and SAT participation
- offers, marketplace, and operator trust surfaces

## Origin

This repository began from MIT-licensed upstream agent code.

That matters for attribution:

- copied or adapted code keeps required upstream notices where applicable
- bundled third-party code, assets, data, and fonts keep their own notices where required

See:

- [`LICENSE`](https://github.com/fased-ai/agent/blob/main/LICENSE)
- [`THIRD_PARTY_NOTICES.md`](https://github.com/fased-ai/agent/blob/main/THIRD_PARTY_NOTICES.md)

## Current maintainer surface

Current public stewardship and product direction are under Fcode AI for the Fased
brand/runtime surface.

That does not erase required upstream attribution for copied, adapted, or bundled
third-party code.

## Credits policy

Fased does not use a permanent homepage-style contributor wall as the main source of
truth.

Contributor recognition should come from:

- git history
- pull requests
- release notes
- targeted acknowledgements where they materially help users understand origin or scope
