# Polished Walkthrough Screenshots

These images are generated from the real screenshots in:

- `/images/screenshots/local/`
- `/images/screenshots/remote/`
- `/images/screenshots/web/`

They are framed for the beginner walkthrough so readers can see the important
step without decoding tiny raw terminal or dashboard captures.

Regenerate from the repository root:

```bash
bash docs/ops/marketing/template/assets/operator-school/screenshots/render-polished-screenshots.sh
```
