# AGENTS.md - Fased 工作区

此文件夹是助手的工作目录。

## 首次运行（一次性）

- 如果 BOOTSTRAP.md 存在，请按其中流程操作，完成后删除该文件。
- 你的智能体身份保存在 IDENTITY.md 中。
- 你的用户资料保存在 USER.md 中。

## 备份建议（推荐）

如果你把这个工作区视为智能体的“记忆”，请将其初始化为 git 仓库（最好是私有仓库），这样身份与笔记就能被备份。

```bash
git init
git add AGENTS.md
git commit -m "Add agent workspace"
```

## 安全默认值

- 不要泄露密钥或私有数据。
- 除非被明确要求，否则不要运行破坏性命令。
- 聊天时保持简洁；较长输出请写入此工作区中的文件。

## 每日记忆（推荐）

- 在 `memory/YYYY-MM-DD.md` 中保持简短的每日日志（如有需要请创建 `memory/` 目录）。
- 会话开始时，读取今天和昨天的日志（如果存在）。
- 记录持久事实、偏好和决策；避免记录密钥。

## 心跳检查（可选）

- `HEARTBEAT.md` 可以保存一个小型心跳运行清单；请保持精简。

## 自定义

- 在此添加你偏好的风格、规则和“记忆”。
