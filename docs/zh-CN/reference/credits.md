## 当前项目

Fased 是这个仓库当前的产品方向。

公开仓库现在主要承载：

- 自托管智能体运行时
- Gateway 与控制 UI
- 钱包与签名策略
- Fased Network 与 SAT 参与
- Offers、Marketplace 与 operator trust 相关界面

## 起源

这个仓库起步于 MIT 许可的上游智能体代码。

这意味着在归属上需要区分：

- 对于复制或改编的代码，仓库许可证里需要保留适用的上游归属声明
- 对于打包进仓库的第三方代码、字体、数据和资源，也必须保留各自要求的 notice

参见：

- [`LICENSE`](https://github.com/fased-ai/agent/blob/main/LICENSE)
- [`THIRD_PARTY_NOTICES.md`](https://github.com/fased-ai/agent/blob/main/THIRD_PARTY_NOTICES.md)

## 当前维护面

当前公开产品方向与维护面由 Fcode AI 以 Fased 品牌推进。

这并不会替代复制、改编或 bundled third-party code 所需保留的上游归属。

## 致谢策略

Fased 不再把首页式贡献者墙作为主要真相来源。

贡献者识别应主要来自：

- git 历史
- pull request
- 发布说明
- 在确有必要时的定向说明
