# Wallets on Hosting

Hosting uses the same WEN and wallet experience as Local. Its differences are service supervision, isolated signer ownership and remote administration.

Use the managed installer and updater, verified prebuilt packages, protected signer sockets and private administration. Keep the control interface off public Funnel exposure and restrict tailnet access to approved owners. Network membership does not confer signer authority.

Create an ordinary wallet and configure a verified RPC. Start read-only, then enable only required WEN operations under positive amount and fee budgets. Approve bounded delegation separately for unattended work.

Verify gateway and signer readiness, a representative permitted operation, and restart recovery on the actual host. Do not infer 2 GB performance or cross-platform support from source tests alone.

See [Wallet CLI](/cli/wallet) and [Wallet policies](/plugins/crypto/wallet-roles-and-policies).
