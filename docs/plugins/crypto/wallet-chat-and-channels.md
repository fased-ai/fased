# Wallet actions in chat

Chat can help inspect WEN facts and prepare an allowed action. It does not receive private keys or unrestricted signing authority. Select the wallet explicitly or use an approved assignment, then apply the same review, policy and execution checks as the WEN desk.

A message, skill, channel integration or Network invitation cannot grant spending authority. Unattended tasks require a separately approved bounded delegation. Keep additional channel capabilities disabled until needed.

Report submission separately from confirmation. After a disconnect or restart, reconcile the original request and show its recorded outcome instead of silently repeating the action.

See [Wallet CLI](/cli/wallet) and [Wallet policies](/plugins/crypto/wallet-roles-and-policies).
